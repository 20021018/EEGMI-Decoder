# EEGMI-Decoder

Algorithm implementation for motor-imagery EEG decoding with a lightweight spiking neural network (SNN) and Online Euclidean Alignment. The research project combines model design with streaming FPGA acceleration.

## Project stack

The full project uses **SystemVerilog and Python**, with **PyTorch and Vivado**. This repository is intended for the algorithm implementation.

## Code availability

Algorithm code has not yet been released.
